# 翻译与排版规范

本规范不绑定某一学科、期刊或某篇论文；术语、章节和缩写均以当前原文为准。

## 语气与完整性

- 采用学术论文书面语，简洁、客观，不使用口语化连接词。
- 逐段对应原文；不写摘要式改写，不删减实验/计算条件、数值、对照组和限定语。
- `Here, we ...` 译为“本文/我们……”均可，但全文统一；方法部分优先“我们”。
- `may/might/suggest` 保留不确定性，不升级为确定结论。
- 原文的 `first`、`remarkably`、`unexpectedly` 等评价词保留，不额外添加原文没有的因果关系。

## 术语管理

- 不预置某一领域的固定术语表。先通读论文，建立本文术语表，再开始全文翻译。
- 同一英文术语全文只用一种译法；首次出现时写“中文（English original）”，后文按需使用缩写。
- 作者自定义的缩写、变量名、样品/模型编号不擅自展开或改写；以原文定义为准。
- 学科术语优先采用该领域中文文献的通行译法；没有通行译法时，首次出现保留英文原词。
- 通用文档标签可直接采用下表；学科术语按论文内容补充。

| English | 中文 |
|---|---|
| Abstract | 摘要 |
| Keywords | 关键词 |
| Main text | 正文 |
| Supporting Information / Supplementary Information | 补充信息 |
| Figure / Table / Equation | 图 / 表 / 公式 |
| Supplementary Figure / Table | 补充图 / 补充表 |
| Author contributions | 作者贡献 |
| Data availability | 数据可用性 |
| Conflict of interest | 利益冲突 |
| Corresponding author | 通讯作者 |
| Acknowledgements / Acknowledgments | 致谢 |
| References | 参考文献 |

## 数字、单位与符号

- 数字与单位之间保留半角空格：`10 nm`、`25 °C`、`1.5 h`、`5 mg/L`。
- 百分号、角度和温度按原文位置：`30%`、`0°`、`−30°`、`±60°`。
- 乘号用 `×`，减号用 `−`（U+2212），范围用 `–`（en dash）。
- 上标：`10⁶`、`cm²`、`m³`；同位素、电荷、幂次等按原文。
- 变量下标用 `~...~`：`x~i~`、`σ~max~`、`E~a~`、`T~c~`。
- 复合上下标：`E~a~^eff^`，不要写成 `E_a^eff` 纯文本。
- 公式中的量符号斜体、单位正体；变量命名以原文为准。

## 图与图注

- 图号格式：`图 1.`（点后一个空格），补充图 `图 S1.`。
- 图注逐句翻译，子图 `(a)`、`(b)` 保留；子图说明之间用中文分号或句号。
- 图内英文刻度、图例、面板标记不翻译、不擦除、不重绘。
- 图注不要写进图片内部；用 Word 段落放在图下，9 pt，居中/两端对齐。
- 图片宽度：单栏图 8–10 cm，多面板 14–17 cm；以不超正文宽度、不压页脚为准。
- 图像至少 200 dpi；优先使用 PDF 内嵌原图，避免二次截图。
- 矢量图按图区 300 dpi 渲染；不要包含正文、页眉或图注。

## 表与表注

- 表号：`表 1` 或 `表 S1`；表题在表上方，9.5 pt 加粗居中。
- 表头浅灰蓝底 `#E8EEF4`，表体 8.4–9 pt，数值列居中，文字列左对齐。
- 表格宽度不超正文；列宽按内容分配，避免最后一列挤压换行。
- 表注在表下，8.3 pt：“注：括号中的数值表示……”。
- 表格必须整体保持在同一页；表头跨页重复；行设置 `cantSplit`。

## 公式

- 展示公式单独成段、居中，宽度 12–16 cm。
- 公式中的向量/矩阵按原文样式（粗体、斜体、正体）处理；单位正体。
- 公式后正文接着解释变量；不要把公式压成一行纯文本。
- 公式图白底黑字，不添加公式编号，除非原文有编号。
- 行内简单符号用 `~下标~`、`^上标^`；多行、分式、求和/积分等用 mathtext 渲染。

## 参考文献

- 保留英文原文、作者顺序、期刊名、年份、卷期、页码、DOI。
- 只修复 PDF 抽取造成的伪空格/断词，例如：
  - `well- known` → `well-known`
  - `1234− 1240` → `1234−1240`
  - `Fig. 3` 中的异常空格按原排版清理
- 不把 `(1)` 编号改成 `[1]`，不翻译标题。
- 不把跨行断词强行拼接成错误单词；不确定时保留原词形。
- 参考文献 7.9–8.2 pt，悬挂缩进 0.62 cm，行距 1.05–1.1。

## 首页与页眉页脚

- 首页：中文标题（19.5 pt，黑体，允许两行）→ 英文原题（8.6 pt 斜体灰）→ 作者 → 单位 → 通讯作者 → DOI → 说明。
- 摘要放在浅灰底、左侧深红竖线的文本框中；摘要 9.8 pt，关键词 9.5 pt。
- 页眉 7.5 pt 灰色，底部细线，写“中文译稿 · 中文短标题”；页脚“第 X 页 / 共 Y 页”8 pt。
- 首页说明固定为：“说明：本文件为中文参考译稿，专业术语与数据以英文原文为准；为保持数据原貌，插图沿用原文，图内英文标注未作改动。”

## 章节结构

- 按原文顺序保留章节，不套用固定模板；原文没有小标题时，不要为了“好看”硬造小节。
- 常见章节可译为：摘要、引言、方法、结果、讨论、结论、数据可用性、补充信息、作者信息、致谢、参考文献。
- 补充信息按原文编号（S1、S2……）排列，每个条目为“标题 + 图/表 + 图注/表注”。
- 作者单位、通讯作者、致谢、利益冲突声明翻译为中文；参考文献保留英文。
